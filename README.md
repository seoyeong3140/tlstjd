그래프: 방향성 없음, 순환 있음
그래프와 트리의 차이점: 루트 노드-트리: 반드시 존재(루트: 부모, 노드: 자식)/그래프: 존재하지 않을 수도 있음(순환이 있으면) 

# 2026.08.28
맹목적 탐색(무정보 탐색): 상태 공간에 관한 정보 없이 모든 상태를 규칙에 따라 탐색하는 방법....> 기계적 순서로 모든 상태 탐색. 분기점에서 갈 방향 무작위로 선정->노드X
맹목적 탐색 방법: 깊이 우선 탐색, 너비 우선 탐색
ex) 미로(왼손, 오른손 법칙)
깊이 우선 탐색(DFS): 한칸씩 앞으로 계속 전진하여 탐색하는 방법(갈 수 있는 경우가 많음...> 왼쪽 먼저 방문...> 왼손 법칙), 막다른 길에 다다르거나 길이 없는 경우 이전 상태 준 다른 경로로 갈 수 있는 분기점까지 되돌아가 재탐색(재방문시 저장X...>'방문 안 한다')
너비 우선 탐색(BFS): 넓고 얇게 탐색(왼손 법칙), 반문한 적이 있는 분기점은 재방문X, 가능한 모든 것 확인 후 다음으로 넘어감, 천천히 깊어지며 탐색...>연구에서는 BFS가 DFS보다 좋음
DFS와 BFS의 차이: 트리 탐색에서의 큰 차이는X, DFS는 경우에 따라 더 간단한 경로를 놓치고 복잡한 경로를 제시할 수도 있음
정보 이용 탐색(휴리스틱 탐색, 경험적 탐색): 상태 공간에 관한 정보를 활용하여 지능적으로 그래프의 일부만 효과적으로 탐색함으로써 가까운 근삿값을 빨리 찾을 수 있음->정보O
정보 이용 탐색 방법: 언덕 등반 탐색, 최상우선탐색, A* 알고리즘
확률O -> 실패가 존재, 무조건 성공이 아님
탐색-맹목적 탐색, 정보 이용 탐색...> 트리구조

# 2026.08.31
정보 이용 탐색(휴리스틱 탐색): 이전 경험이나 지식 바탕, 이때 만들어진 정보-휴리스틱 정보, 문제의 해가 정확하게 나오지 않을 때 or 정해진 시간 안에 모든 탐색을 완료하지 못할 때 유용
언덕 등반 탐색(HCS): 경험적 탐색, 현재 지점에서 경험에 의한 평가 함숫값이 가장 좋은 주변 지점을 하나씩 선택해서 확장, 그리디 알고리즘, 지역적으로도 최적의 해이면서 전체적으로도 최적의 해를 찾는 문제에 적합(주변에서 차근차근 해결, 작게작게)
맹목적 탐색과의 차이: 맹목적-모든 경우의 수를 다 세팅해 둠, 정보 이용 탐색-정답에 가까워질 때(함숫값이 높을 떄)로 가지를 뻗음...>경우의 수 2분의 1로 줄어듦
최상우선탐색(BFS): 최적 우선 탐색 or 최고 우선 탐색, 평가함수와 open, close 리스트를 사용하여 리스트 안에 있는 요소 중 가장 유리한 것 선택(평가 함수가 가장 좋은 값을 close 리스트에 추가, 언덕 등반 탐색과 달리 선택되지 못한 노드도 다시 고려하는 과정을 거침
A* 알고리즘: 최상우선탐색과 유사. 다만 최상우선탐색 알고리즘의 평가 함수를 적용하는 부분에서 단순히 말고리즘의   , 성능에 큰 영향을 미치는 평가 함수를 잘 정해야 함
미니맥스알고리즘: 게임에 많이 쓰임

맹목적 탐색(무정보 탐색): 상태 공간에 관한 정보 없이 모든 상태를 규칙에 따라 탐색하는 방법....> 기계적 순서로 모든 상태 탐색. 분기점에서 갈 방향 무작위로 선정->노드X
맹목적 탐색 방법: 깊이 우선 탐색, 너비 우선 탐색
ex) 미로(왼손, 오른손 법칙)
깊이 우선 탐색(DFS): 한칸씩 앞으로 계속 전진하여 탐색하는 방법(갈 수 있는 경우가 많음...> 왼쪽 먼저 방문...> 왼손 법칙), 막다른 길에 다다르거나 길이 없는 경우 이전 상태 준 다른 경로로 갈 수 있는 분기점까지 되돌아가 재탐색(재방문시 저장X...>'방문 안 한다')
너비 우선 탐색(BFS): 넓고 얇게 탐색(왼손 법칙), 반문한 적이 있는 분기점은 재방문X, 가능한 모든 것 확인 후 다음으로 넘어감, 천천히 깊어지며 탐색...>연구에서는 BFS가 DFS보다 좋음
DFS와 BFS의 차이: 트리 탐색에서의 큰 차이는X, DFS는 경우에 따라 더 간단한 경로를 놓치고 복잡한 경로를 제시할 수도 있음
정보 이용 탐색(휴리스틱 탐색, 경험적 탐색): 상태 공간에 관한 정보를 활용하여 지능적으로 그래프의 일부만 효과적으로 탐색함으로써 가까운 근삿값을 빨리 찾을 수 있음->정보O
정보 이용 탐색 방법: 언덕 등반 탐색, 최상우 탐색, A* 알고리즘
확률O -> 실패가 존재, 무조건 성공이 아님
탐색-맹목적 탐색, 정보 이용 탐색...> 트리구조

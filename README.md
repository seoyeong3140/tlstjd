   2-2. 너비 우선 탐색(BFS): 넓고 얇게 탐색(왼손 법칙)

      2) 가능한 모든 것 확인 후 다음으로 넘어감
      3) 천천히 깊어지며 탐색...>연구에서는 BFS가 DFS보다 좋음
   2-3. DFS와 BFS의 차이
      1) 트리 탐색에서의 큰 차이는X

1. 인공신경망과 딥러닝
   1-1. 인공신경망은 여러 개의 인공 뉴런으로 이루어져 있으며, 딥러닝은 이 중 한 종류이다.
   1-2. 페셉트론
      1) 뉴런의 작동 방식을 모방하여 컴퓨터 프로그램을 구현한 것
      2) 여러 개의 값을 입력 받아 각 입력값에 가중치를 곱한 후 모두 더하고, 이 값에 편향을 더한 후 활성화 함수에 넣어 나온 결과를 출력
      3) 가중치와 편향을 조정하면 원하는 값을 출력하는 다양한 목적의 퍼셉트론을 만들 수 있음
      4) 활성화 함수: 판단 기준
   1-2. 딥러닝
      1) 인간의 뇌는 수많은 뉴런이 네트워크를 형성하여 서로 정보를 주고 받으며 복잡한 문제를 해결함
      2) 인공신경망: 인간의 뇌를 모방하여 뉴런의 역할을 하는 퍼셉트론의 수를 늘리고 이 퍼셉트론들을 네트워크처럼 연결한 인공지능 모델
      3) 단층 퍼셉트론 -> 다층 퍼셉트론 -> 딥러닝
      4) 학습: 실제값과 예측값의 차이를 최소화하도록 퍼셉트론의 연결강도를 조절하는 것
      5) 다층 퍼셉트론
         5-1) 단층 퍼셉트론을 여러 개 연결한 것
         5-2) 입력층: 데이터가 들어오는 곳
         5-3) 출력층: 최종 결과를 출력하는 곳
         5-4) 은닉층: 입력층과 출력층 사이
      6) 딥러닝 구조
         6-1) 입력층과 출력층 사이에 여러 개의 은닉층이 있는 신경망
      7) 딥러닝의 학습: 데이터를 넣어 출력한 결과(예측값)를 실제값과 비교하여 오차를 줄이는 방향으로 가중치 편향을 조절하는 과정으로 반복하며 실력을 키우는 데 이러한 과정
         7-1) 순전파: 딥러닝에서 학습하기 위해 데이터를 입력하고 은닉층과 출력층을 거쳐 결과를 출력하는 과정
            7-1. 1) 우리가 여러 문제를 풀고, 한 번에 채점을 하는 방식과 비슷
            7-1. 2) 배치 사이즈: 딥러닝에서 결과 출력을 위해 한번에 넣는 샘플의 수
         7-2) 오차 계산
            7-2. 1) 오차: 딥러닝 모델이 출력한 예측값과 실젯값 사이의 차이
            7-2. 2) 손실함수: 이 오차를 계산하는 함수
            7-2. 3) 손실함수는 분류 모델과 예측 모델에 따라 다르게 사용
            7-2. 4) 예츨 모델에서는 배치 사이즈의 수치대로 나온 출력값과 실젯값의 오차를 제곱하여 평균을 낸 평균제곱오차를 손실 함수로 사용
         7-3) 역전파
            7-3. 1) 오차 계산 후 이 오차를 줄이도록 순전파의 반대 방향으로 이동하며 각 퍼셉트론의 가중치와 편향을 수정
            7-3. 2) 이때 가중치와 편향을 수정하는 최적화 알고리즘인 경사 하강법을 사용하여 모델의 손실함수를 최소화하기 위해 가중치와 편향을 조정
            7-3. 3) 순전파, 오차 계산, 역전파를 반복하는 과정에서 오차가 충분히 작아지면 학습을 종료하고 딥러닝 모델의 성능을 최적화한다.
